# КИНОТЕАТР — Live API (реальный Discord онлайн)

Этот сервер агрегирует **количество участников, онлайн и игровых активностей** для сайта. Он **не передаёт** ники, Discord ID или отдельные игровые активности участников. Никаких фейковых цифр.

## Что нужно подключить

1. В Discord включи **Developer Mode** → правой кнопкой на иконке сервера → **Copy Server ID**. Это публичный `DISCORD_GUILD_ID` (длинное число, **не токен**).
2. В сервере Discord открой **Server Settings → Widget**, включи **Enable Server Widget** (если такая настройка доступна). Это даёт публичный `presence_count` для онлайна. Бот не обязателен для этого режима.
3. Для реальной статистики по играм зайди на https://discord.com/developers/applications → **New Application → Bot**. В настройках бота включи **Presence Intent** (привилегированное разрешение). Добавь бота на **свой сервер** через OAuth2 Installation. Не давай ему Administrator; для чтения присутствия это не требуется.
4. Создай на Render, Railway или аналогичном сервисе Node.js Web Service из папки `live-api/`. Укажи `DISCORD_GUILD_ID`, `DISCORD_BOT_TOKEN` и `ALLOWED_ORIGINS` в **переменных окружения хостинга**. Build command: `npm install`; Start command: `npm start`; рабочая папка: `live-api`.
5. Получи URL сервиса вида `https://example.onrender.com/api/stats`. Укажи его в файле **`live.config.js`** в корне сайта:

```js
window.KINOTEATR_LIVE = Object.freeze({
  apiUrl: 'https://YOUR-SERVICE.onrender.com/api/stats',
  guildId: 'YOUR_DISCORD_SERVER_ID'
});
```

**Никогда не публикуй BOT TOKEN в GitHub, HTML, JS, скриншотах и чате.** Токен вводится только в приватные Environment Variables хостинга. Не коммить `.env`.

## Режим без бота

Если задать `DISCORD_GUILD_ID`, включить Widget и оставить `DISCORD_BOT_TOKEN` пустым, API сможет показывать **только онлайн**. Игровые активности и общее число участников останутся «—»; для них требуется бот.

Можно также указать один `guildId` в `live.config.js` и оставить `apiUrl` пустым — браузер попробует запросить публичный виджет напрямую. Если Discord не разрешает CORS, используй сервер-прокси выше.

## Формат ответа

`GET /api/stats`:

```json
{
  "members": 128,
  "online": 27,
  "playing": 12,
  "games": { "arizona": 2, "dota": 3, "cs2": 4, "minecraft": 1 },
  "source": "bot",
  "updatedAt": "2026-11-08T00:00:00.000Z"
}
```

**Числа в примере только для документации, не используются на сайте.** В widget-only режиме поля `members`, `playing` и `games` будут `null`. Если данных нет, API возвращает HTTP 503, а сайт не показывает выдуманные цифры.

## Важные нюансы

- Discord может не передавать невидимые, скрытые или выключенные активности; эти люди в игровую статистику не попадут.
- Arizona RP может отображаться как GTA San Andreas или другое имя, и бот **не может достоверно угадать сервер RP**. Поэтому считаются только активности с `Arizona` в названии. Иначе будет ложное завышение.
- Discord предоставляет `GUILD_PRESENCES` через привилегированный intent; он должен быть включён в Developer Portal. Для больших/верифицированных ботов Discord может требовать дополнительное одобрение.
- Сайт запрашивает API примерно раз в 45 секунд. В сервисе публичный Discord Widget кэшируется на 25 секунд. Сервису нужен постоянно доступный хостинг; на спящих тарифах возможны задержки.
- `/health` возвращает технический статус сервиса без секретов.
