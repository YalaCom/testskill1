# КИНОТЕАТР — игровой Discord-сервер

Промосайт для сообщества **КИНОТЕАТР**: Arizona RP, Dota 2, Counter-Strike 2, Minecraft и другие игры. Не кино, не театр — свои люди.

## Что внутри

- Кинематографичный первый экран с 3D-тикетом и эффектом параллакса.
- Четыре оригинальных векторных постера игр (не используются чужие игровые скриншоты).
- Анимированные карточки с подробным описанием каждой игры.
- Имитация Discord-чата, показывающая атмосферу сообщества (вымышленный пример, не реальные сообщения).
- **Рабочая рулетка:** случайно выбирает одну из четырёх игр с анимацией и конфетти.
- GSAP-анимации появления и ScrollTrigger при прокрутке; базовый сайт работает и без CDN.
- Мобильное меню, FAQ, модальные окна, SEO-метаданные, поддержка клавиатуры и `prefers-reduced-motion`.
- Пасхалка: набери `kino` на клавиатуре.

## Как запустить

Никакой установки не требуется: открой `index.html` в браузере. Для локальной разработки можно воспользоваться `python -m http.server 8000` и открыть `http://localhost:8000`.

## Как подключить Discord

В файле **`main.js`** измени первую настройку:

```js
const DISCORD_INVITE = "https://discord.gg/ТВОЙ-КОД";
```

Используй **свою реальную** ссылку-приглашение. Пока она пустая, все кнопки Discord показывают аккуратное информационное окно — они не ведут на выдуманный сервер.

**Если используешь одностраничный `index.html` из корня GitHub**, найди внутри этого файла `const DISCORD_INVITE = "";` и вставь туда ссылку.

## Варианты сборки

- `index.html` + `styles.css` + `main.js` + папка `assets/` — исходная версия, которую удобно редактировать.
- `standalone/index.html` — полностью собранная версия в одном файле; изображения, CSS и JS встроены. Именно её можно использовать для быстрого запуска GitHub Pages.

## GitHub Pages

1. Открой свой GitHub-репозиторий.
2. Перейди в **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**.
4. Укажи **main** и **/(root)**, затем нажми **Save**.
5. Публикация обычно занимает некоторое время. После активации адрес будет вида `https://yalacom.github.io/testskill1/`.

В корне репозитория должна лежать **собранная одностраничная версия `index.html`**, которую я загрузил для простого GitHub Pages. Отдельные исходники находятся в скачиваемом архиве.

## Дизайн и технологии

HTML, CSS, JavaScript без сборщика. GSAP + ScrollTrigger (через jsDelivr), Manrope + Unbounded (через Google Fonts). Иконки и игровые постеры реализованы векторной графикой, созданной специально для этого сайта. Весь основной контент, изображения и функциональность доступны без подключения внешних API; шрифты и GSAP при наличии интернета улучшают отображение и анимацию.
