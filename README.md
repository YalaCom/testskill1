# РИТМ — спокойный тренажёр печати

**РИТМ** — бесплатный тренажёр слепой печати на русском и английском. Его можно развернуть на GitHub Pages за несколько кликов. Не нужны аккаунт, backend, база данных, аналитика или сторонний API.

## Что умеет

- **Тест на время:** 15 / 30 / 60 / 120 секунд. Слова добавляются, когда заканчивается текущая последовательность.
- **Тест по количеству слов:** 25 / 50 / 100 слов, завершается по набору последнего символа.
- **8 уроков:** домашний ряд, верхний, нижний, переходы, заглавные буквы, цифры и свободная практика. Каждый следующий урок открывается, когда точность в предыдущем достигла **95%**. Уроки отдельные для RU и EN.
- **Связный текст:** четыре авторских текста на каждом языке.
- **Работа над ошибками:** тренажёр чаще подбирает слова с ошибочными клавишами из последних 25 сессий.
- **Построчный режим:** как только набрана строка, следующая плавно поднимается на её место; доступен предварительный просмотр следующих строк. Работает в каждом режиме и на телефоне; при возврате Backspace строка возвращается.
- **В реальном времени:** WPM, точность, таймер, подсветка ошибочных/верных букв, текущая позиция, прогресс, интерактивная подсказка пальца и виртуальная раскладка.
- **После теста:** WPM, raw WPM, точность, стабильность, время, нажатия, количество ошибок, сложные клавиши и график темпа.
- **Аналитика:** личный рекорд, средний WPM, точность, время занятий, стрик по дням, история попыток, экспорт CSV, очистка данных.
- **Удобство:** тёмная/светлая тема, режим фокуса, опциональные синтезированные звуки клавиш, мобильный экран, поддержка клавиатуры, автоматический прогресс в localStorage.
- **Офлайн:** service worker позволяет повторно открыть ранее загруженный сайт без сети (при запуске по HTTPS/localhost); шрифты имеют системный fallback.

## Запуск локально

Открой `index.html` в браузере. Для проверки service worker рекомендуется локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Затем перейди на `http://localhost:8000`. Внешние шрифты загружаются из Google Fonts; остальная логика не зависит от интернета. Нужен современный браузер с JavaScript.

## Публикация GitHub Pages

Открой репозиторий → **Settings → Pages → Deploy from a branch → main / (root) → Save**. Все пути относительные; сайт корректно работает и на адресе вида `https://USER.github.io/REPOSITORY/`.

## Как вычисляются результаты

- **WPM** = число символов в правильных позициях / 5 / минуты. Пробелы и знаки препинания считаются символами. Это **скорость верного ввода**, а не количество слов из словаря.
- **Raw WPM** = число введённых символов (включая исправленные) / 5 / минуты.
- **Точность** = правильные *нажатия* / все введённые нажатия × 100%. Backspace не стирает ранее допущенные ошибки из статистики.
- **Стабильность** = 100 × (1 − стандартное отклонение / среднее) для секундных отрезков скорости, ограничено от 0 до 100. Менее трёх отрезков — нет оценки.
- Рекорды и средний WPM считаются по тестовым сессиям (время, слова, текст) продолжительностью не менее 5 секунд с минимум 20 правильными символами. Начальные сверхкороткие уроки не увеличивают рекорд искусственно.
- **Урок пройден** при точности ≥95%. В остальных режимах нет искусственного порога прохождения.
- График теста показывает накопленное среднее WPM; стабильность оценивает темп по секундным интервалам.

Алгоритм расчётов описан открыто, так как разные сайты могут считать net WPM и raw WPM по-разному.

## Обучающая логика

Последовательные уроки развивают знакомство с клавишами и позициями пальцев. Обратная связь по ошибкам помогает повторять трудные сочетания. Порог точности 95% — **проектное учебное правило**, а не универсальный научный стандарт. Практика фокусируется на точности, повторении и устойчивом движении, а не обещает конкретный результат за несколько дней.

Источники, которые повлияли на решения:

- [TypingClub: принципы обучения, точность, домашний ряд](https://typingclub.typingclub.com/docs/user-guide/introduction/best-practices-for-teaching-keyboarding.html)
- [Aalto University / CHI 2018: Observations on Typing from 136 Million Keystrokes](https://userinterfaces.aalto.fi/136Mkeystrokes/)
- [Aalto University / CHI 2016: How We Type](https://userinterfaces.aalto.fi/how-we-type/resources/HowWeType_CHI16.pdf)
- [Monkeytype: режимы, обратная связь, метрики и практики UX](https://monkeytype.com/about)
- [TypingTest Pro: методика подсчёта WPM](https://typingtestpro.zendesk.com/hc/en-us/articles/4655755114898-How-is-WPM-calculated)

## Управление

Кликни по области текста и печатай. `Tab` → `Enter` перезапускает попытку, `Esc` снимает фокус. Можно нажать «Заново». Вставка из буфера запрещена для честности результатов; Backspace разрешён. При смене языка необходимо переключить физическую раскладку клавиатуры на нужную. На телефоне используется экранная клавиатура устройства.

## Хранение и приватность

Сайт **не отправляет тексты и результаты на сервер**. Настройки, результаты, ошибки и пройденные уроки хранятся в `localStorage` данного браузера. Они не синхронизируются между устройствами и могут исчезнуть при очистке данных браузера. Для переноса результата можно скачать CSV. Код не загружает пользовательские данные в сторонние сервисы. Опционально используются Google Fonts (только для отображения шрифтов).

## Структура

- `index.html` — семантическая разметка и SEO.
- `styles.css` — адаптивный интерфейс, темы, анимации, доступность.
- `app.js` — упражнения, ввод, аналитика, прогресс, локальное сохранение.
- `sw.js` + `manifest.webmanifest` — офлайн-кэш и установка приложения.
- `favicon.svg` — иконка.

Примечание: это самостоятельная статическая версия. Здесь нет облачной синхронизации, публичных таблиц лидеров или борьбы с читами на сервере.


## Обновление дизайна — Quiet Edition

- Спокойный графитовый интерфейс, мягкий зелёный акцент и более строгая типографика.
- Режим **Фокус** и его контрастная панель ввода сохранены без изменения механики тестов.
- `refinement.css` хранит визуальные изменения отдельно от базовой разметки и компонентов.
- Смена строки автоматически плавно передвигает текущую строку в начало окна; Backspace возвращает предыдущую.
- Файлы CSS/JS подключены с версией `v=4`, service worker использует версию `ritm-cache-v4` и проверяет обновления. Прогресс в `localStorage` не удаляется.

Если сайт уже был открыт до публикации, проверь его по адресу `https://yalacom.github.io/testskill1/?v=4`, а при необходимости обнови браузер через Ctrl+Shift+R. Очистка данных сайта удалит локальную статистику — сначала экспортируй CSV.
