# ритм. — Mineral Edition (v6)

Рабочий тренажёр печати на русском и английском с 8 уроками, тестами на время или количество слов, упражнениями по ошибкам, сохранением истории и локальной статистикой. Сайт разворачивается на GitHub Pages, **без сервера и без регистрации**.

## Что нового

- Единая новая цветовая система: **минеральный светлый фон** `#F6F4F0`, **чернильно-синий** `#283B53`, **приглушённый сине-стальной** `#5C729C`. Визуально заменены прежние зелёные темы, не добавлен ещё один CSS-слой поверх старого.
- Одно оформление в `styles.css` с понятными базовыми переменными. Файлы `refinement.css` и `sage.css` удалены.
- Форма одобренного логотипа «ритм.» сохранена и перекрашена в новую палитру, чтобы знак был частью единой системы. Сохранена прозрачность PNG.
- Макет панели **Фокус** сохранён. Цвета стали тёмно-синими; фон занимает всю область экрана без границ или прямоугольных переходов.
- Правильный ввод даёт короткий сине-бирюзовый отклик, ошибка — мягкий розово-красный; на последних 12 секундах режима на время красный свет постепенно усиливается. Отклик не меняет расчёт WPM или ошибок.
- Обновлены адреса CSS/JS и Service Worker до `v6` для обновления без смешения старых стилей и новых сценариев. Локальная история не затрагивается.

## Локальный запуск

Можно открыть `index.html` или запустить `python -m http.server 8000` и перейти на `http://localhost:8000`.

## Публикация

В репозитории GitHub открой `Settings → Pages → Deploy from a branch → main → /(root)`.

### Структура

- `index.html` — страница тренажёра.
- `styles.css` — **все** стили и палитры в одном месте.
- `app.js` — ввод, уроки, ошибки, тесты, графики и данные.
- `logo.png` — логотип на прозрачном фоне.
- `favicon.svg` — иконка из ритмичных полос.
- `manifest.webmanifest` и `sw.js` — PWA и офлайн-кэш.

Рекорды и настройки сохраняются локально в браузере, не отправляются на сервер.
